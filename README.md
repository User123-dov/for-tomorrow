# 为了明日 · 考研学习终端

一个跑在自己电脑上的个人学习管理网站，**本机访问 + 手机/远程访问**。

## 启动

双击 `启动学习助手.bat` 即可（首次运行会自动安装依赖）。浏览器打开 http://localhost:5175

## 手机 / 远程访问

启动时命令行会打印所有可访问地址，也可在「设置」页查看：

- **局域网地址**（192.168.x.x / 172.x.x.x）：手机与电脑连同一 WiFi 时可用。注意校园网通常隔离设备，此方式在校园网内可能不通。
- **Tailscale 地址**（100.x.x.x）：**校园网环境推荐**。在电脑和手机都安装 Tailscale（[tailscale.com/download](https://tailscale.com/download)，免费）并登录同一账号，之后手机在任何网络下都能访问电脑上的网站，流量端到端加密、仅限自己的设备。装好后该地址会自动出现在「设置」页。

安全建议：非本机访问前，在「设置 → 手机/远程访问」开启访问密码。

> 前提：电脑开机且程序在运行。数据都在电脑本地。

## 主菜单（首屏）

打开网站先进方舟式主菜单大厅：右上角资源条（倒计时/今日时长/待办/资料数），右下角斜杠菜单（终端·作战·仓库·档案·情报·采集·设定），底部滚动公告。

**换成自己的背景图**：把任意图片放到 `data/files/home-bg.jpg`，刷新即自动生效（建议 1920×1080 以上、暗色调更清晰）。删掉该文件即恢复默认几何背景。

## 功能

| 模块 | 说明 |
|---|---|
| 🏠 仪表盘 | 考研倒计时、今日任务、学习计时器、本周时长图表、最近收藏 |
| 📅 学习计划 | 每日任务（截止日/优先级/顺延）、科目章节树（未学/学习中/已掌握）、学习时长记录 |
| 📚 资料库 | 收藏链接、网页剪藏（提取正文离线读）、上传 PDF 等文件、标签 + 全文搜索 |
| 🎬 视频库 | 粘贴 B站/YouTube 链接自动抓取信息，站内嵌入播放、观看状态、学习笔记；可选下载到本地 |
| 🌐 采集中心 | 批量粘贴网址，自动识别 B站视频 / 文章 / 文件直链并入库；支持配置登录站点的 Cookie |
| ⚙️ 设置 | 考研日期、科目管理、站点 Cookie、局域网访问密码、yt-dlp 状态 |

## 视频下载（可选）

1. 下载 [yt-dlp.exe](https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe)
2. 放入本目录的 `tools/` 文件夹（没有就新建）
3. 刷新网页，视频库里即可出现「下载到本地」按钮

可选安装 ffmpeg.exe（同目录）以获得更高清晰度。注意：清晰度由平台决定（B站未登录账号最高 480P）；受版权保护/加密的内容无法下载；仅供个人学习使用。

## 抓取需要登录的网站（如领先在线）

前提是你有该网站的正规账号：

1. 浏览器登录该网站
2. 按 `F12` → Network → 刷新 → 点第一个请求 → 复制请求头里 `Cookie:` 后面的整串内容
3. 粘贴到「设置 → 站点 Cookie」，域名填如 `lingxianvip.com`
4. 点「测试」确认生效，然后去「采集中心」粘贴该站的课程/讲义页面地址

> 只抓取你自己账号有权限访问的内容、仅个人学习使用；本工具不做绕过付费或解密受保护视频流的功能。若某课程视频因平台加密无法下载，可用「收藏链接 + 笔记」方式收纳。

## 数据与备份

所有数据都在 `data/` 文件夹（SQLite 数据库 + 上传/下载的文件）。备份：关闭程序后复制整个 `data/` 文件夹；恢复：复制回来即可。

## 技术栈

Node.js 24（内置 SQLite）+ Express + Vue 3（无构建步骤）。依赖仅 6 个纯 JS 包，Windows 下无需任何编译环境。
